# 🌊 Flood Prediction using Machine Learning

A web-based Flood Prediction System built using Machine Learning (Decision Tree Classifier) and Flask framework.

This application predicts whether a flood is likely to occur based on environmental and geographical parameters.

---

## 🚀 Project Overview

Floods are one of the most common natural disasters.  
This project uses historical flood-related data to train a Decision Tree model and predict flood occurrence.

The system takes multiple environmental inputs and predicts:

- ⚠ Flood Likely
- ✅ No Flood Expected

## 📊 Machine Learning Model

- Algorithm Used: Decision Tree Classifier
- Feature Scaling: StandardScaler
- Model Saving: Joblib
- Model File: `floods.save`
- Scaler File: `transform.save`
